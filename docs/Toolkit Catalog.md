## Mission 20 Financial Decision-Making Toolkit

**Paired app:** [Mission 20](https://mission20.ltecwithlance.com/)

A facilitator-focused toolkit that turns playful $20 challenges into structured experiential learning.

### Five core competencies
1. **Resource Allocation**: use limited resources toward an objective.
2. **Opportunity Cost**: identify what was given up.
3. **Value Assessment**: judge worth beyond price.
4. **Decision-Making Under Constraints**: adapt when rules, time, or availability limit options.
5. **Reflection and Financial Agency**: explain, evaluate, and transfer choices.

### Learning cycle
**Understand → Plan → Choose → Explain → Compare → Transfer**

### Implementation resources
- Challenge archetypes
- Educational mapping
- Mission selection guidance
- Instructional depth options
- Evidence of learning
- Debrief protocols
- Privacy, equity, and safety guidance
- Assessment guidance
- Single-session, multi-session, recurring series, showcase, and simulation formats

## Portfolio implementation model

The toolkits are designed around a common pattern:

**App for engagement + toolkit for implementation + training for adoption + evidence for improvement**

The goal is not simply to provide information. The goal is to help users practice a decision, document what happened, and improve the process over time.
